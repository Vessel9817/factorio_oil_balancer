# Factorio Oil Balancer

[![CI][ci-badge]][ci-workflow]

## Installation

Within a Python 3.14 virtual environment:

```shell
pip install -r requirements-freeze.txt
```

## Running

```sh
# Windows
py -m src.main

# Linux
python3 -m src.main
```
